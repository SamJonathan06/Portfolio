# 🚀 Personal Portfolio Website

Welcome to my personal portfolio! This project showcases my skills, projects, and professional journey as a developer. Designed with modern aesthetics and built for performance, it serves as a central hub for my work.

## 🎯 The Problem Solved
I needed a performant, visually appealing, and scalable way to present my resume, projects, and skills to potential employers and collaborators. Traditional PDF resumes lack interactivity, so I built a responsive web experience that demonstrates my coding abilities firsthand.

## 🛠️ Tools & Technologies
*   **Framework:** React with TypeScript (Vite)
*   **Styling:** Vanilla CSS (Focusing on CSS Grid/Flexbox and custom animations)
*   **Deployment:** Netlify Drop
*   **Version Control:** Git & GitHub

## ✨ Key Features & Effects
*   **Responsive Design:** Fully adaptable layout that looks great on mobile, tablet, and desktop.
*   **Modern Aesthetics:** Clean UI with thoughtful typography and whitespace.
*   **Type Safety:** Built with TypeScript to ensure code quality and prevent runtime errors.
*   **Fast Build Times:** Configured with Vite for lightning-fast Hot Module Replacement (HMR) and optimized production builds.

## 🚀 How to Run Locally
1. Clone the repository: `git clone <https://github.com/SamJonathan06/Portfolio.git>`
2. Navigate to the directory: `cd portfolio`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
